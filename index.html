Como adicionar imagem

  1. Envie a imagem para a pasta assets/posts no GitHub.
  2. Abra data/posts.json e adicione um novo item na lista.
  3. Salve o commit. O GitHub Pages atualiza o site sozinho depois do deploy.

Assim as imagens ficam no repositorio e aparecem para todo mundo que acessar o site.
